# Lumen — Waitlist signup ✦

A modern **waitlist / free-trial signup** landing — rebuilt as a showcase by **[Governor Studio](https://governor-studio.vercel.app)**.

## Features
- ✅ Live inline validation (name + email) with animated error messages
- 🎉 Animated success state (confirmation + queue position)
- 🪟 Glassmorphism card on a gradient backdrop, social proof
- 📱 Responsive, accessible, reduced-motion aware

## Stack
**Vite · React 19 · Tailwind CSS v4 · Framer Motion**

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
```

---

Rebuilt from a static challenge into a real, validated signup flow to demonstrate Governor Studio's delivery.
